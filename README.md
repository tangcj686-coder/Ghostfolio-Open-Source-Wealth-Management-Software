## 🛠️ Troubleshooting Common Issues

**The application doesn't start.**  
Make sure you extracted all files from the ZIP before running the executable. Also, close any firewall pop-up that asks for permission—click "Allow."

**I see a blank white screen.**  
Wait 30 seconds. The first start can be slow as it initializes the database. If it stays blank, close the window and reopen the executable.

**My assets aren't showing up.**  
Double-check the ticker symbol. Use proper format like `MSFT` (Microsoft) or `ETH` (Ethereum). For ETFs, try the common abbreviation like `SPY` or `QQQ`.

**The numbers look wrong.**  
Prices update automatically, but if you see stale data, click the refresh button (circular arrow) in the top menu.
